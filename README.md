# パスワードジェネレーター

## 概要

長さや使う文字の種類を選ぶだけで、安全で強力なパスワードを生成できるWebアプリです。
パスワードの生成はすべてブラウザ内で完結し、生成したパスワードがサーバーへ送信されることはありません。

## 機能

- パスワードの長さをスライダーで調整（4〜64文字、初期値16文字）
- 使用する文字の種類を選択（大文字 / 小文字 / 数字 / 記号）
  - 選んだ種類の文字が最低1文字ずつ含まれるように調整
- パスワード強度を4段階（弱い / 普通 / 強い / 非常に強い）で判定し、色付きのバーで表示
- ワンクリックでクリップボードにコピー（コピー完了・エラーを通知で表示）
- ページを開いた時点で1つ自動生成。Enterキーでも再生成可能
- セキュリティ対策
  - Content Security Policy とセキュリティヘッダー（クリックジャッキング対策など）を設定
  - 検索エンジンにインデックスさせない設定（noindex）
  - 外部ライブラリ・CDN・トラッキングは不使用
- モバイル対応のレスポンシブデザイン

## 使用技術

- HTML
- CSS（カスタムプロパティ / Flexbox / CSS Grid / メディアクエリ）
- JavaScript（フレームワーク不使用のバニラJS）
- Web Crypto API（`crypto.getRandomValues()` による暗号学的に安全な乱数）
- Clipboard API
- デプロイ: Cloudflare Pages（`_headers` ファイルでセキュリティヘッダーを付与）
